# 🚀 Zapret Telegram Fix

> **Быстрый фикс и обход замедления Telegram на ПК в один клик (Standalone EXE).**

[![GitHub Release](https://img.shields.io/github/v/release/your-username/zapret-telegram-fix?color=blue&label=Скачать%20EXE)](../../releases/latest)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Автономная утилита на базе **zapret (`winws` / `windivert`)** для восстановления работы Telegram на компьютере (загрузка фото, видео, голосовые сообщения и звонки).

---

## ⚡️ Быстрый старт

1. Скачайте **`zapret-telegram-v29.9.9.exe`** на странице **[Releases](../../releases/latest)**.
2. Запустите файл **от имени Администратора** (*Правая кнопка мыши ➔ Запуск от имени администратора*).
3. Оставьте окно открытым во время работы Telegram.

> ℹ️ *Если возникнут проблемы с загрузкой, попробуйте другие сборки (`v19.9.1`, `v1.9.2`) из списка релизов.*
